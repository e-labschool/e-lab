Reviewer scope: `ph-calculator-visualizer`, `h-oh-balance`, `neutralization-particle-visualizer`, `equivalence-point`, `titration-ph-curve`, `buffer-action-visualizer`, `chocolate-wrapping-rate`, `collision-theory-visualizer`.

Date: 2026-11-16.

## How this was done, and what is and is not verified

- Read the code of every engine and its chemistry/data files, and the existing audit docs (`docs/SIMULATION_AUDIT_REPORT.md`, `docs/simulation-audit-results.json`). The existing audit covers shell/layout/fullscreen/contrast only and states "Scientific content was not re-verified". Nothing below repeats its findings; it is a first scientific and pedagogical review of these eight.
- Built the app to a temp dir (`/tmp/elab-dist`), served with `vite preview`, drove each simulation in headless Chromium (Playwright, SwiftShader) at 1366x768, 1366x900/1440x1000, fullscreen and 390x844. Probe scripts are in `/tmp/simreview/scripts/`, screenshots in `/tmp/simreview/acids/`.
- **Verified by running:** every numeric claim marked "observed". For the titration solver I wrote an independent charge-balance solver and compared the UI's pH meter at 8 volumes for each of 4 reagent pairs (32 comparisons, all within 0.01 pH). For the Maxwell-Boltzmann percentages I recomputed the fractions numerically.
- **Verified against sources (web):** indicator pH ranges and colours (ibchem.com IB25 page and an extraction of the 2025 data booklet), ethanoic acid pKa 4.76 (ibchem), Kw = 1.00 x 10^-14 at 298.15 K (data booklet extraction).
- **Reasoned only, not verified in this session:** Ca(OH)2 solubility (~0.01-0.02 mol dm^-3; a web fetch was blocked), H2SO4 pKa2 (~1.99), React StrictMode double-invocation effects (dev-only), keyboard/screen-reader behaviour beyond what the DOM probe showed, reduced-motion behaviour (grep only).
- **Not tested:** Learn-embedded (`compact`) mode (needs Supabase), real touch devices, Safari/Firefox, GPU rendering. Console: no page errors in any of the eight in production build; only blocked external-resource noise from the sandbox.
- The 2025 data booklet extraction gave phenolphthalein as 8.0-10.0 while ibchem lists 8.2-10.0 and the sim uses 8.2-10.0. The extraction tool is a summariser, so please check your own copy of the booklet (see questions).
- There are **no automated tests** for any of these eight simulations (compare `package.json` scripts: ideal-gas, gas-laws, bonding, VSEPR, NMR, IR, MS have model tests; none of these eight do). That is the single biggest reason "flawless" cannot currently be guaranteed or defended.

## 2. H+ - OH- Balance in Water (`h-oh-balance`)

**Verdict.** Add HCl or NaOH drops to "pure water" and watch two log-scaled bars and the pH. The animation choreography is tidy and nothing crashes, but the underlying model is not chemistry: every drop **multiplies** [H+] (or [OH-]) by 5, whatever the current concentration. Real equal drops of the same solution add equal **moles**, so the concentration changes linearly in added amount (pH change per drop shrinks as the solution becomes more acidic). A student who watches this will learn that "each drop changes pH by 0.7". The bars are logarithmic with no axis, so they visually say the opposite of what the numbers say. **Score 3.5/10**: visually fine, scientifically misleading, which for a "flawless" product is the most serious issue in this batch.

## 6. Buffer Action Visualizer (`buffer-action-visualizer`)

**Verdict.** Two 25 cm^3 beakers, one a 0.1/0.1 mol dm^-3 buffer (ethanoic or ammonia) and one "unbuffered", receive small or medium additions of H+ or OH-. Henderson-Hasselbalch is applied correctly in the working range (observed: first 0.2 mmol H+ -> 4.68 buffer vs 2.10 unbuffered; HH check 4.745 + log(2.3/2.7) = 4.675). ## 8. Collision Theory Visualizer (`collision-theory-visualizer`)

## Proposed improvement plan

### What to keep
- **Titration solver** (`solvePH`/`getChemistryState`): correct, verified; extract it into a shared `src/lib/acidBase.js` with a Node test file and reuse it in the Buffer, Equivalence and pH-calculator simulations.
- **MB curve generator** shape (sqrt(E) exp(-E/kT)), but replace the truncated numerical normalisation with the analytic one (AK-61).
- The titration indicator table and colour model (verified ranges), the equivalence-point beam metaphor (AK-26..32 fix), the Neutralization pour-and-pair storyline.

### What to rebuild
1. **H+ - OH- Balance**: rebuild the model on moles and volumes (AK-10, AK-11, AK-12, AK-15). Current model cannot be patched into correctness.
2. **Collision Theory**: rebuild the vessel as a real 2D collision engine with T, concentration, surface-area (particle-size/exposed fraction) and catalyst controls, collisions counted and classified (AK-61..65, 69). The existing MB graph and geometry code can stay.
3. **Chocolate Wrapping**: keep the story, rebuild the input handling and the rate/graph relationship (AK-53..55).

### Specific premium-feel features (in order of teaching value)
1. Shared acid-base engine plus tests (below) so every number on screen is defensible.
2. Predict -> Observe -> Explain mode in Titration, Buffer, Collision, Equivalence (predict pH or curve shape, then reveal; short "why" statement).
3. Data capture: results table, CSV/PNG export, overlay of a previous run (titration, chocolate, buffer pH vs additions).
4. Challenge/assessment modes: unknown-concentration titration, "design a buffer of pH 9.0", "choose the indicator", "what limits the rate".
5. Syllabus tags and IB language on each screen (R3.1.x/R2.2.x), misconception call-outs ("pH change is not linear with drops", "equivalence point is not always pH 7").
6. Keyboard-complete controls, aria-live status, reduced-motion switch, 390 px layout checks.
7. A single viewport-fit layout pattern (controls always visible at 1366x768) used by all of these.

### Suggested order of work
1. **Foundation (S/M):** shared acid-base module + Node tests (`scripts/test-acid-base-model.mjs` style like existing model tests) covering strong/weak pH, titration points, buffer, MB fractions; add the 8 sims to the verification scripts (fixes the "no tests" gap).
2. **Quick wins (S each, about 1-2 days total):** AK-01, 03, 12, 26/33, 34/28 layout, 35, 37, 53, 54, 61 (hide or fix percentages), 64, 66.
3. **Rebuilds:** H-OH balance (AK-10 family), then Collision engine (AK-61..65), then Chocolate (AK-55..58).
4. **Pedagogy layer:** predict/explain, data table/export, challenges for Titration and Buffer.
5. **Polish:** accessibility, reduced-motion, mobile, visual unification of the dark/light panels.
